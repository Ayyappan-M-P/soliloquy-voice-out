# SOLILOQY single-page website

## Build
- Replace the blank home page with the full SOLILOQY experience: sticky navigation, hero, about, pillars and rituals, events, rooms, manifesto, testimonials, join form, and footer.
- Keep all editable copy, room details, rituals, stats, testimonials, and event listings in one data module.
- Create focused reusable pieces for the smiley mascot, 3D cube, section reveals, cards, marquee, RSVP dialog, and contact form.

## Visual direction
- Use the supplied yellow, pink, midnight, paper, and restrained purple palette as semantic design tokens.
- Pair chunky rounded display type with clean body type and handwritten notes.
- Add geometric shapes, dot and wave patterns, torn-paper edges, heavy borders, and hard offset shadows for a polished zine-like rhythm.

## Interaction
- Add word-by-word hero entrance, rotating typewriter lines, cursor-reactive CSS cube, scroll reveals, count-up stats, event filtering, room-door interactions, scroll-spy navigation, mobile menu, marquee, wink confetti, and desktop cursor follower.
- Respect reduced-motion preferences and maintain keyboard, focus, and screen-reader support.
- Validate RSVP and join forms locally and show success messages without storing or sending data.

## Technical details
- Use TanStack Start's existing React/Vite foundation with TypeScript, Tailwind v4, Motion for React, lucide icons, React Hook Form, Zod, Radix dialog primitives, and Sonner.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Verify the finished page on desktop and mobile, including filtering, dialogs, forms, menu navigation, and console health.
